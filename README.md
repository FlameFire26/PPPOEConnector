# PPPOEConnector

本地项目名称：PPPOEConnector。

管理 PPPoE 连接、重连和连接设置的 Windows 桌面工具。

## 开发与运行

技术：VB.NET / .NET Framework 4.8。

入口：`PPPOEConnector.sln`。

使用安装了对应 SDK/工作负载的 Visual Studio 打开解决方案；较旧的工程可能需要兼容性调整。
